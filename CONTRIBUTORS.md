# Contributors

PowerNukkitX does not maintain a manual contributor list. Everyone who has
contributed code is credited automatically on the
[GitHub contributors page](https://github.com/PowerNukkitX/PowerNukkitX/graphs/contributors).

Entries in this file are added by AI coding agents as a review checkpoint,
as described in [AGENTS.md](AGENTS.md). A pull request that still contains
a new entry here has not been reviewed by its author and is closed without
review.
